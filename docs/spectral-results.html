Bipartite Spectral Non-Minimality (Theorem 1.7 / Example 3.33)

In classical Coxeter systems, bipartite Coxeter elements always minimize the spectral radius among all principal elements. In the 6-node bipartite mixed-sign graph example_3_33, the bipartite principal element has a strictly larger spectral radius than the linear principal element:

import sys
sys.path.insert(0, "../src")
sys.path.insert(0, "src")

from mixed_sign_coxeter import MixedSignCoxeterGraph

g = MixedSignCoxeterGraph.example_3_33()
rho_lin = g.spectral_radius([0, 1, 2, 3, 4, 5])
rho_bp = g.spectral_radius([0, 3, 5, 1, 2, 4])
print(f"Bipartite graph: {g.is_bipartite()}")
print(f"Linear principal element   [1,2,3,4,5,6]: rho = {rho_lin:.5f}")
print(f"Bipartite principal element [1,4,6,2,3,5]: rho = {rho_bp:.5f}")
Bipartite graph: True
Linear principal element   [1,2,3,4,5,6]: rho = 3.05129
Bipartite principal element [1,4,6,2,3,5]: rho = 5.55193

Non-Monotonicity of \(\Lambda\) (Remark 3.30)

Adding a positive node along \(A_2(+,-) \subset A_3(-,+,+) \subset A_4(-,+,+,+) \subset A_5(-,+,+,+,+)\) causes the minimal spectral radius \(\Lambda\) to oscillate instead of increasing monotonically:

from mixed_sign_coxeter import MixedSignCoxeterGraph

chain = [
    ("A2(+,-)",       ["+", "-"]),
    ("A3(-,+,+)",     ["-", "+", "+"]),
    ("A4(-,+,+,+)",   ["-", "+", "+", "+"]),
    ("A5(-,+,+,+,+)", ["-", "+", "+", "+", "+"]),
]
for label, signs in chain:
    lam, _ = MixedSignCoxeterGraph.A_n(signs).minimal_spectral_radius()
    print(f"{label:15s}  Lambda = {lam:.5f}")
A2(+,-)          Lambda = 2.61803
A3(-,+,+)        Lambda = 1.00000
A4(-,+,+,+)      Lambda = 2.15372
A5(-,+,+,+,+)    Lambda = 1.88320

Computational Verifications Beyond the Dissertation

Full derivations and tests live in docs/verifications.md and tests/test_verifications.py:

  1. \(W(\widetilde{A_{-n}}) \cong W(D_{n+1})\) for every even \(n\) (isomorphisms.py): An explicit integer matrix \(T\) of \(D_{n+1}\) roots satisfies \(T^T T = -B(\widetilde{A_{-n}})\) and conjugates \(W(\widetilde{A_{-n}})\) onto \(W(D_{n+1})\) of order \(2^n (n+1)!\). For odd \(n\), the cycle is bipartite and \(W(\widetilde{A_{-n}})\) is infinite.
  2. Appendix D in Python: Reproduces the GAP session for \(W(\widetilde{A_{-4}})\), verifies all 16 relators, and proves faithfulness of order \(1920\) via Todd–Coxeter enumeration.
  3. Remark A.3 (Table A.2 completeness) (finite_search.py): Exhaustive search finds 4 additional finite rank-3 graphs and 24 additional finite rank-4 graphs beyond Table A.2 and Figure A.1 (all negative and non-bipartite).
  4. Question 3.35 (principal_search.py): Across 4,026 simply-laced cyclic graphs on 4–6 nodes, the smallest counterexample where the bipartite element fails to minimize is the alternating 4-cycle \((+,-,+,-)\) (formally verified in AlternatingSquare.lean).
  5. Question 2.59 & Single-Defect Cycles (OddCycleSingleDefect.lean, EvenCycleSingleDefect.lean): On \(C_6(+,-,+,-,+,-)\), distinct circulations \(|c| \in \{0, 2, 4\}\) separate \(\rho(w)\) (\(5.82843\), \(4.91314\), \(8.18570\)). Conversely, single-defect cycles exhibit a sharp parity dichotomy: for every odd cycle \(C_{2m+1}(+,-,\dots,-)\) (\(m \ge 1\)), \((w+I)^2(w^{2m}-I)=0\) and \(\rho(w) = 1\), whereas for every even cycle \(C_{2m}(+,-,\dots,-)\) (\(m \ge 2\)), \(w\) has a real eigenvalue \(\lambda \in (-5, -1)\) and hence \(\rho(w) > 1\).
